# ART Rehab Tracker v3.2

Personal ART-branded rehab tracker.

## v3.2 changes
- Added editable workout sessions.
- Edit one exercise per line from the Workouts tab.
- Edits save locally on your device and update Workout Details + Exercise Check-Off.
- Added reset button for each session.
- Export/import now includes custom workout edits.
