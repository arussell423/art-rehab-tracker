# ART Rehab Tracker v3.1

Updated save behaviour:
- Daily checks save by date and update the same date instead of duplicating.
- Session logs save with on-screen confirmation.
- Checklist changes auto-save with confirmation.
- Storage warning appears if Safari/localStorage is unavailable.

For reliable iPhone saving, host through GitHub Pages and open the GitHub Pages URL in Safari, then Add to Home Screen. Avoid opening from ZIP preview or Private Browsing.
