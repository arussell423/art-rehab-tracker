ART Rehab Tracker - easiest GitHub Pages setup

1. Unzip this folder.
2. Create a PUBLIC GitHub repository.
3. Upload ALL files from this folder into the repo root.
4. In GitHub: Settings > Pages
5. Source: Deploy from branch
6. Branch: main
7. Folder: /root
8. Save

Your site will go live at:
https://YOURUSERNAME.github.io/REPONAME/

Then open that link in Safari and use:
Share > Add to Home Screen

If GitHub Pages takes a minute or two to appear, wait and refresh.
